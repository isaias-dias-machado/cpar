# WA1 — Work Assignment, Phase 1 (26-27)

The only **normative** file in the corpus. Everything else is pedagogical support.

## What it mandates (verbatim-ish, use in the report)
1. *(p.1)* Structured methodology, five steps: (i) find hot-spots via profiling;
   (ii) present parallelism alternatives inside the hot-spots;
   (iii) select approach **justified by a scalability analysis**;
   (iv) implement and optimise **on Deucalion, ARM queues**;
   (v) measure and discuss performance.
2. *(p.1)* Deliverables (`zip` must unzip to directory named after the pair, e.g. `pg43000_pg54000/`):
   - 2-page PDF report (**IEEE template**, annexes excluded but may be read);
   - subdirectory with *all source code; no executables*;
   - one single `Makefile` producing `./md` in the base directory, with a
     `run` target that executes the parallel version (`make run`, reading
     `inputdata.txt` on stdin).
3. *(p.2)* Evaluation — **the single home of this fact**:
   **(i)** 30% execution time on Deucalion ARM node (best PU count
   expressed via `export OMP_NUM_THREADS ?= N` in the Makefile);
   **(ii)** 30% chosen approach, OpenMP implementation, code legibility —
   *data races have a strong penalty*;
   **(iii)** 40% report quality (strong scalability, profiling, models & metrics).
4. *(p.2)* Flag-type requirements: `-fopenmp` **mandatory**; `-march=native`
   suggested for the target ARM machine; `-g -fno-omit-frame-pointer`
   recommended for `perf`. Graded build: **GCC/15.2.0 on an ARM node**.
5. *(p.1)* Dates: submission until 23:59 **25-Nov-26**; defence happens with
   WA-Phase 2 oral (Jan'27).

## Case study as stated (p.1)
Simple MD of argon atoms (origin: FoleyLab/MolecularDynamics, modified for
the course), Newton mechanics, Lennard-Jones forces, Velocity-Verlet
integration, elastic walls. See `notes/MD_simulations.md` and `equations.md`.

## Gotchas
- *(p.2)* Annex B is the provided Makefile **without** flags — this repo's
  `Makefile` already adds `-O3 -ffast-math`; graded run may differ ⇒ decide
  flags explicitly.
- `OMP_NUM_THREADS` uses `?=` precisely so the grader can override it.
- *(p.2)* Profiling advice: seed with small N (slide says *N=200 at line 214*
  of the original file). The repo-side line drift is a *current* fact, kept
  in one home: `topics/md-case-study.md` §"Line-number discrepancies".
